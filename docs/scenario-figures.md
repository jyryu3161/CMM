# Contributor scenario-figure manifest

This is a development/GUI-regression manifest, not publication validation evidence. The figures
are generated artifacts and are intentionally not distributed with CMM.

Generated by driving the real Qt workbench under the offscreen platform, fully self-contained
inside `CMM/` (no parent-folder paths). Run from the `CMM/` directory with the project venv:

```bash
QT_QPA_PLATFORM=offscreen CMM_OUTPUT_DIR=./temp_figures_new \
    PYTHONPATH=src .venv/bin/python -m cmm.app.screenshots
QT_QPA_PLATFORM=offscreen CMM_OUTPUT_DIR=./temp_figures_new \
    PYTHONPATH=src .venv/bin/python -m cmm.app.succinate_scenario
QT_QPA_PLATFORM=offscreen CMM_OUTPUT_DIR=./temp_figures_new \
    PYTHONPATH=src .venv/bin/python -m cmm.app.genome_scale_scenario
```

The images themselves are **not tracked in git** — they are reproducible from the commands
above, and a committed copy goes stale the moment the code changes. This file is the manifest:
it says what each figure shows, so the set can be checked after regenerating. Record the CMM
commit, model fingerprint, solver/version and capabilities, condition, and output hashes whenever
the set is regenerated. Do not cite this page as evidence for numerical or biological claims;
use the versioned source tables and validation artifacts for the study instead.

## Notes

- The `fig_*.png` files are the paper-ready 300-DPI figures; the GUI captures (`*_NN_*.png`) are
  ~100-DPI screen grabs for software documentation, not main-text raster figures.
- Reaction tables now size the reaction-id column to take the slack, so long ids such as
  `Biomass_Ecoli_core` are no longer truncated on genome-scale models.
